# 🎮 Four in a Row – Connect Four Game

## 📌 About the Project
Four in a Row is a simple two-player console-based game developed using Python. The objective is to connect four tiles of the same player horizontally, vertically, or diagonally to win.

## 🛠️ Technologies Used
- Python 3
- Standard Python Library (`sys`)

## 🎯 Features
- Two-player gameplay (Player X and Player O)
- 7-column × 6-row game board
- Horizontal, vertical, and diagonal win detection
- Input validation
- Detects a draw when the board is full
- Option to play again
- Quit option during gameplay

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python "charles python.py"
```

## 🎲 How to Play
- Player X starts first.
- Player O plays next.
- Enter a column number between 1 and 7 to drop your tile.
- Connect four tiles in a row (horizontal, vertical, or diagonal) to win.
- Enter `QUIT` to exit the game.

## 🏆 Winning Condition
The first player to connect four tiles in a row horizontally, vertically, or diagonally wins the game.
